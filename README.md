Этот проект содержит сервис по работе с заявками на получение справок.
Предоставляет возможность сотрудникам  сотрудникам подавать запросы и отслеживать их статус, 
а бухгалтерам — обрабатывать заявки в единой очереди с фиксацией всех изменений

Требования: установленный C# версии net10.0

Структура проекта:
- /Program.cs  — файл запуска программы,
- /Certificates - содержит файлы описывающие справки,
- /Employees - содержит классы сотрудников,
- /Requests - содержит классы работы с заявками.

Для запуска :
- откройте проект в Visual Studio,
- в меню Build выберите Start Without Debugging (или нажмите Ctrl + F5).
